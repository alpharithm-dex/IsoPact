# Final architecture freeze

After Stage 14, no feature work is allowed. Permitted changes are submission fixes, repository/documentation corrections, critical security fixes, and demo-availability fixes. Any consequential code or configuration change requires the relevant regression suites and a new release commit. Settlement semantics, architectural limitations, benchmark evidence, and authority boundaries must not be weakened for the pitch.

Decision: no additional Google model was added for bonus points. Stability and verifiable architecture take priority over a speculative integration.
