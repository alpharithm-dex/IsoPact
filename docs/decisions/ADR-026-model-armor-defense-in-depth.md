# ADR-026: Model Armor is defense in depth

Status: Accepted

Screen untrusted customer/ticket/enterprise text immediately before Gemini compiler and Resolver calls. Use prompt-injection/jailbreak and malicious-URI filters where the live project permits a template. Persist only screened-input hash and non-sensitive result metadata.

On detection or service failure, defer the affected LLM reasoning path. Deterministic policy, gateway decisions, evidence ranks, invariant evaluation and receipt verification do not call Model Armor and cannot be modified by its output. Model Armor may miss attacks and therefore never becomes an authority boundary.
